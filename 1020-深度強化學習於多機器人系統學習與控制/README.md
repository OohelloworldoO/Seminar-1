# 書報討論演講報告：深度強化學習於多機器人系統學習與控制

## 一、基本資料

|    Date    |    Speaker    |                title                 |
| :--------: | :-----------: | :----------------------------------: |
| 2026/10/20 | 蔣惟丞 副教授 | 深度強化學習於多機器人系統學習與控制 |

## 二、簡介（Introduction）

本次演講介紹如何讓機器人透過與環境互動學習決策，並進一步討論多個機器人如何形成協作行為。演講由強化學習、Q-Learning 與深度 Q 網路（Deep Q-Network, DQN）的基本概念出發，延伸至群體互動、通訊成本及無通訊條件下的合作學習。[1]

單一機器人的感測範圍、移動能力與可執行工作有限，多機器人系統則可透過分工，完成區域巡檢、協同搬運、探索與任務分派等工作。然而，增加機器人數量並不等於自然形成合作。每個個體的選擇都可能影響其他成員，因此系統除了需要學會完成自己的工作，也需要考慮團隊需求與彼此之間的協調。

本報告以課堂照片為主要依據，補充必要的強化學習概念，並從資訊取得、回饋設計及群體決策三個角度整理演講內容。

## 三、演講重點與相關技術

### 3.1 代理人與環境的互動

投影片以「分析、學習、決策」說明代理人的功能。代理人根據環境資訊判斷目前情況，選擇行動，再由行動造成的結果調整後續決策。[1]

| 基本概念        | 意義                   | 機器人任務中的例子     |
| :-------------- | :--------------------- | :--------------------- |
| 代理人（Agent） | 執行決策的個體         | 一部移動機器人         |
| 狀態或觀測      | 描述環境或感測到的資訊 | 位置、障礙物、影像     |
| 行動（Action）  | 代理人可以採取的選擇   | 前進、轉向、停止       |
| 獎勵（Reward）  | 用來評估行動結果的回饋 | 抵達終點獲得正回饋     |
| 策略（Policy）  | 根據資訊選擇行動的規則 | 在不同位置選擇移動方向 |

這些例子用於解釋概念，不代表講者所有實驗均採用相同設定。實際機器人常只能感測部分環境，因此「接收到觀測」也不能直接等同於「掌握完整狀態」。

### 3.2 Q-Learning：由行動結果學習價值

課堂以格子世界說明 Q-Learning，示範獎勵設定為：撞牆 −100、抵達終點 +100、其他情況 0。[1] 代理人藉由嘗試不同方向，逐步學習哪些選擇較有利。

Q 值可以理解為在某個狀態採取特定行動後，預期能取得的累積回報，而不只是眼前的一次獎勵。以下為補充說明用的標準表格型 Q-Learning 更新式：[2]

$$
Q(s_t,a_t) \leftarrow Q(s_t,a_t)+\alpha\left[r_{t+1}+\gamma\max_{a'}Q(s_{t+1},a')-Q(s_t,a_t)\right]
$$

其中，$\alpha$ 為學習率，$\gamma$ 為折扣因子，$r_{t+1}$ 為本次行動後取得的獎勵。若下一狀態為終止狀態，後續價值項設為零。更新的重點是利用新觀察到的回饋，修正原先對行動價值的估計。

課堂的數值是教學例子，並非所有導航任務的固定規則。從此例延伸思考，若只獎勵抵達終點而沒有明確時間成本，是否偏好較短路徑，仍取決於折扣因子及其他環境設定；不能只看終點獎勵便認定一定學出最短路徑。

### 3.3 DQN：從表格走向神經網路

當狀態包含影像或大量感測資訊時，逐一儲存每個狀態與行動的 Q 值較不實際。課堂的 DQN 示意圖以影像或感測狀態作為輸入，經過神經網路後，輸出上、下、左、右等行動的價值估計。[1]

| 比較項目 | 表格型 Q-Learning            | DQN                      |
| :------- | :--------------------------- | :----------------------- |
| 價值表示 | 表格中的數值                 | 神經網路近似的數值       |
| 狀態處理 | 適合可枚舉的較小離散狀態空間 | 可處理較高維度的狀態輸入 |
| 更新對象 | 對應的表格項目               | 神經網路參數             |
| 需要注意 | 狀態數增加造成表格膨脹       | 訓練穩定性與估計誤差     |

補充文獻中，經典 DQN 結合經驗回放與目標網路以改善訓練穩定性。[3] 這些屬於方法背景補充，並非由目前照片確認的課堂實作設定。神經網路輸出的 Q 值是估計值，也不等於某動作的成功機率。

### 3.4 群體機器人的需求與應用

講者從三個面向說明群體機器人的價值：工作範圍擴大、工作分工更細，以及環境適應能力提升。多部機器人可分散巡檢與監控，也可配置不同角色，在障礙物或個體能力限制下協調工作。[1]

課堂提出的應用包括協同搬運、追捕與包圍、區域巡檢，以及足球與任務分派。這些任務對合作的要求不同。例如，搬運需要方向與動作配合，巡檢需要避免重複覆蓋，足球則同時涉及進攻、防守與支援。

這使我理解，多機器人研究不能只將單一機器人的演算法複製多份，還需要處理角色分配、動作衝突及團隊整體表現。

### 3.5 三種群體互動關係

投影片將群體互動分為完全合作、完全競爭，以及合作與競爭並存，並指出不同任務會定義不同的學習目標與回饋機制。[1]

| 互動關係       | 核心特徵                   | 課堂對應例子                        |
| :------------- | :------------------------- | :---------------------------------- |
| 完全合作       | 成員共享團隊目標           | 合作搬運、聯合追捕；Overcooked 圖例 |
| 完全競爭       | 個體目標互相衝突           | 對抗遊戲與競賽；Bomberman 圖例      |
| 合作與競爭並存 | 部分關係合作，部分關係競爭 | 足球的隊內合作與隊際競爭            |

分類應依實際任務與獎勵設定判斷，而不是只根據遊戲名稱。以足球為例，同隊成員的共同目標與對手的目標不同，因此同一環境中可同時存在合作及競爭。

### 3.6 完全通訊的優點與限制

在完全通訊型架構中，機器人交換較廣泛的狀態與動作資訊，提供協調所需的依據。課堂同時指出，其限制是聯合空間與傳輸成本較高。[1]

以簡化例子說明，若每部機器人都有 $m$ 個離散行動，$N$ 部機器人的聯合行動組合數可達 $m^N$。例如四部機器人各有五個行動，共有 $5^4=625$ 種組合。這是本文的概念說明，不是課堂實驗數據。

因此，資訊交換與決策計算需要一起考慮：分享更多資訊可能有助協作，也可能提高傳輸負擔與處理成本。研究設計應說清楚哪些資訊在訓練時可用，以及哪些資訊在實際執行時可用。

### 3.7 無通訊條件下的深度合作學習

第 17 頁投影片提出「將個體行動價值與合作傾向融合，形成更符合群體需求的決策」。示意圖包含 DQN 的 Q-value、DCM 的 C-value，以及接收兩者的 ADF，並與環境互動。[1]

依這張圖可以確認的是：決策不只參考個體行動價值，也納入合作相關訊號。但目前照片沒有提供 DCM、ADF 的完整英文名稱、訓練目標或數學融合公式，因此本報告保留原縮寫，不自行假設它們採用加權平均或其他特定演算法。

「無通訊」也不宜理解成完全沒有資訊。機器人仍可能透過感測環境取得觀測，並觀察其他個體行動帶來的變化。至於課堂方法允許哪些觀測、是否在訓練時共享資訊，仍需要完整研究資料才能確定。

### 3.8 階層式控制與研究驗證

演講大綱列出「DCM 與三組實驗」，以及「階層式控制：行為融合與目標協調」。然而，這次提供的照片未包含三組實驗的設定、結果或完整階層控制架構。[1]

因此，可以將其列為演講的研究方向，但無法據此宣稱成功率提升多少、收斂速度更快，或已證明在特定真實機器人上有效。一般而言，階層設計可用來區分目標選擇與動作執行；這裡僅作概念補充，不代表講者實作一定採取特定層數或模型。

## 四、心得與討論（Reflection and Discussion）

### 4.1 個體學得好，不代表團隊合作得好

本次演講讓我注意到，單一代理人的最佳選擇不一定能帶來團隊最佳結果。例如，在狹窄區域中，每部機器人都急著朝自己的目標前進，反而可能互相阻擋。真正的協作需要考慮其他成員的行動與整體任務，而不只是各自提高分數。

這也改變了我對多機器人系統的理解：研究重點不只是「讓更多機器人同時運作」，而是要設計讓個體決策能彼此配合的機制。

### 4.2 獎勵設計就是把問題轉成學習目標

撞牆扣分與抵達終點加分的例子，看起來簡單，卻說明了獎勵如何影響學習方向。若只追求速度，可能忽略碰撞；若只要求避免碰撞，又可能讓代理人過度保守。對群體任務而言，還需要思考個體貢獻與團隊成果應如何反映在回饋中。

我認為，學習強化學習時不能只記住演算法名稱，還要理解狀態、行動與獎勵如何對應實際需求。這些定義會決定系統究竟在學習什麼。

### 4.3 應從限制條件判斷方法的價值

完全通訊與無通訊合作的比較，讓我理解資訊條件也是研究問題的一部分。若不同方法使用的資訊量不一樣，只比較最終分數可能不公平。實際評估應同時說明資訊來源、機器人數量、任務難度與通訊負擔。

對我而言，這是一個值得保留的研究習慣：先確認方法在什麼條件下運作，再判斷其優點是否符合應用需求。

### 4.4 我希望進一步釐清的問題

若要深入閱讀這項研究，我會優先了解三個問題：第一，DCM 的合作訊號如何定義及訓練；第二，ADF 如何在個體價值與合作傾向之間做決策；第三，所謂無通訊的限制是只適用於執行階段，還是也涵蓋訓練階段。

在實驗方面，我希望看到移除合作模組後的比較，以及機器人數量、障礙配置改變時的表現。這些是本文提出的後續閱讀與驗證方向，不是對講者尚未提供之實驗的結論。

## 五、結論

本次演講從代理人與環境互動的基本觀念，介紹 Q-Learning 與 DQN，再延伸至群體機器人的合作、競爭及資訊交換問題。多機器人系統的價值在於分工與協調，但也增加了決策與資訊管理的難度。

我最大的收穫是理解：深度強化學習的應用不只在模型本身，更包含任務定義、獎勵設計、資訊限制及團隊行為的整合。無通訊合作學習提供值得探索的方向，而其實際效果仍應由完整的架構說明與實驗證據支持。
